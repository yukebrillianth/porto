## Writing Style

Use:

- First person ("I'm...", "I build...", "My work...")
- Confident but not arrogant.
- Technical but understandable.
- Concise and modern.
- Authentic and human.
- Evidence-based.
- Suitable for an engineering portfolio.

Avoid:

- Generic phrases such as "passionate developer with a strong passion for technology."
- Excessive buzzwords.
- Calling the user a "guru", "expert", "visionary", or "10x engineer".
- Overclaiming leadership or technical ownership that is not documented.
- Making the bio sound like a resume bullet list.
- Making the user sound exclusively like a robotics engineer.
- Making the user sound exclusively like a web developer.
- Focusing heavily on high-school achievements.
- Inventing metrics, users, performance improvements, rankings, awards, or responsibilities.
